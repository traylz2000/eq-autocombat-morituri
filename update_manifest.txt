note=## 2026-10-27
note=
note=- **Enrage alerts are loud now (`lua/tac/alerts.lua` 1.1.0).** Enrage, Rampage and Summoned play a built-in alarm, three loud rising whoops, instead of the quiet `/beep` ding. Each trigger's **Sound** is now a picker: **Alarm (loud, built in)**, **Beep (quiet)** or **Sound file (.wav)**. The alarm is `config/moriac_alarm.wav` and plays through Windows' own sound player, so it doesn't hold up the game. If a sound can't be played, the alert beeps instead. Saved alerts switch over on their own: the default Enrage, Rampage and Summoned triggers move to the alarm, and any sound you picked yourself stays. Try it with `/ac alerts test 1`.
note=
note=- **One download to install: `MoriAC-full.zip`.** New players no longer need the Triune AutoCombat full zip. Each [MoriAC release](https://github.com/traylz2000/eq-autocombat-morituri/releases/latest) has one zip that holds MoriAC (`lua/`, `config/`) plus the zone navmeshes and game database (`resources/`). Extract it into the MacroQuest folder and you're done. Upstream Triune was archived on 2026-10-11, and the `resources/` files come unchanged from its final V3.2 release, used with gennro's permission. The install guide is now four steps. Anyone who already has `resources/` can still use the small download (`lua` and `config` only). The in-game updater is unchanged.
note=
note=- **Auto AA buys checked priorities again, in your order (`lua/tac/auto_aa.lua` 1.4.0).**
note=  - Why it did nothing: priorities waited for the **Bank** threshold, and saved loadouts default that to 100 unspent AA. A checked Healing Gift sat there until you had 100 points. Priorities now buy as soon as you can afford them. **Wait for the bank** (in the Priorities panel) brings the old behaviour back. The fireworks cap spender still waits for the bank.
note=  - New **Priority** column next to each AA's name: type 1-9. Priority 1 is bought first, and ties go alphabetical. Leave it blank and the AA is never bought automatically. This replaces the old checkbox. Checked AAs from before start at 1.
note=  - New **Priorities** panel above the AA list. It shows the numbered AAs in buy order, each with its Priority box, an **Up to** rank (stop at rank 3 instead of max), its status and a remove button. The panel is at least five rows tall. **Save up for the top one** stops lower priorities from spending the points the top AA is waiting for.
note=  - A status line says what auto-spend is doing: buying X, waiting for points, in combat, moving, saving up, or nothing left to buy.
note=  - The old 5-point floor is gone, so a 2-point AA can be bought with 2 points.
note=  - New filters under the search box: **class** ("Usable by Bst" and so on: that class's own AAs, the archetype AAs it qualifies for, and the General / Special AAs every class gets; pair it with the Class tab for its own AAs only. "Class unknown" lists Class-tab AAs not yet matched), **AA tab** (General / Archetype / Class / Special), **kind** (Activated, Passive, Pet, Healing, Damage, Defense, Mana / endurance), **progress** (Can buy now, Not started, In progress, Maxed) and **Search descriptions**. Class matching is partial until the server's AA export arrives. A `DATA.aa_classes` table in `moriac_data.lua` will feed it then.
note=  - `/ac aastatus` lists the priorities in buy order, with their Up to rank. `/ac aaprio <name> <1-9>` sets a priority from chat.

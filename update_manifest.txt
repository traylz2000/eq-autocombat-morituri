note=- **New plugin: Timed Commands (`lua/tac/timers.lua`).** It runs a command every N minutes.
note=  - Ships with `/say kratos` every 10 minutes for the Morituri buff. The first run is 5 s after MoriAC loads.
note=  - Each timer has a command (any slash command; text without a `/` is said), an interval (1-120 min), *When* (always, only while MoriAC is running, or only out of combat), and *Run it when MoriAC loads*.
note=  - A timer never runs while you are dead, zoning or casting. When it comes due while held back, it runs as soon as it is allowed instead of a whole interval later. It works while MoriAC is paused.
note=  - `/ac timers [list|now <n>|on <n>|off <n>]`. `/ac kratos` says it now and restarts the timer. Settings are under Setup -> Plugins -> Timed Commands.
note=  - Tests: Suite M11. Suite 88 and Suite 92 now count 26 shipped plugins.
note=
note=- **New mode: Boss (submodes DPS and Tank)** for raid boss fights, where a second boss may be up across the room.
note=  - It fights only mobs that are already engaged and inside the **fight area**: a circle (*Fight area radius*, default 100) around the camp spot, or around where Boss mode started. It never chases past the edge, and walks back to the centre after 3 s with nothing to fight.
note=  - **Boss vs adds:** set *Boss names* (comma-separated, part of the name is enough; **Add Target** or `/ac bossname target`). With none set, any named mob is the boss. Every other engaged mob in the area is an add.
note=  - **Adds first.** DPS kills the lowest-HP add, so every box converges on the same one, and switches only if another add is 10 points lower. Once the adds are dead it joins on the boss at *Join the boss at HP* (default 98%).
note=  - **DPS fights from behind the target:** melee sticks to its back, and bow and caster styles walk round behind it at range between casts. This pauses while you have the target's aggro.
note=  - **Tank:** picks up mobs that are not on it first (adds before the boss), faces its target, and when a mob on it is outside its front arc, steps 12 ft to the spot inside the area that puts them all in front.
note=  - A forced XTarget still outranks everything. Pets attack with you, as in Manual and Puller.
note=  - `/ac boss [dps|tank]`, `/ac bossname [target|clear|<names>]`. Mode & Pulling has a **Boss fight** section with a live readout of the boss, the number of adds, and what you're on.
note=  - Tests: Suite M10 covers name matching, add-before-boss order, the DPS HP wait, the tank's loose-mob pick and the back-step geometry. The smoke test renders both Boss submodes.
note=  - Check in game:
note=    - Two bosses up: only the one inside the area is fought.
note=    - Adds die before the boss.
note=    - Melee DPS end up on the boss's back.
note=    - The tank steps out of a sandwich.

note=- **The updater now installs updates (`lua/tac/update_check.lua`).** The old checker asked GitHub for the latest *release*, and MoriAC has never published one, so it always said "404 not found". It now reads a file list that every publish writes, compares it with your files, and can install what changed.
note=  - About 20 seconds after MoriAC starts it checks, then tells you in chat and in a popup how many files changed, and shows the newest changelog section.
note=  - `/ac update install` (or **Update Now**) downloads only the changed files from GitHub. It checks each one's size and CRC-32 against the list. If any file doesn't match, nothing is installed. Then it swaps them in and keeps each old copy as `<file>.bak`. Then `/ac restart` on each character loads the new version.
note=  - Only `lua/` and `config/` files are updated. Your settings files and `config/ingame.cfg` are never touched. A lock file stops two boxed characters from installing at the same moment.
note=  - Like the old checker, it never starts a process and never makes the game wait: downloads run on Windows' own HTTP worker and are polled.
note=  - `/ac update [now|install|show|skip|unskip|auto on|off]`.
note=  - Tests: Suite 107 is rewritten for the updater: manifest parsing, CRC-32, which files count as changed, the `.new` / `.bak` swap on a real folder, and refusing paths outside `lua/` and `config/`.
note=  - Check in game:
note=    - `/ac update` finds an update after the next publish.
note=    - **Update Now** installs it.
note=    - `/ac restart` loads it.
note=    - The `.bak` files sit next to the replaced ones.

note=- **New plugin: Alerts (`lua/tac/alerts.lua`).** It plays a sound, flashes a big line at the top of the screen and echoes to chat when a trigger fires. It works while MoriAC is paused too.
note=  - Default triggers:
note=    - On: **Enrage** (`#1# has become ENRAGED.`), **Rampage**, **Summoned**.
note=    - Off: **Tell** and **Low HP** (below 35%).
note=  - Add your own under Setup -> Plugins -> Alerts:
note=    - Any chat line, as an MQ event pattern. `#*#` matches anything, and `#1#` matches anything and shows it in the alert.
note=    - Or my HP / mana below a percentage. These fire once and re-arm 5% above.
note=  - Each trigger has:
note=    - Sound: blank plays `/beep`; a `.wav` file name plays that file through `/beep <file>`.
note=    - When: always, in combat only, or only while MoriAC is running.
note=    - A cooldown, and a flash on/off.
note=    - A **Test** button.
note=  - `/ac alerts [list|mute|unmute|test <n>]`.
note=  - Tests: Suite M9.
note=  - Check in game:
note=    - **Test** beeps and flashes.
note=    - A real enrage fires the alert.
note=    - A `.wav` path plays the file. Not yet verified that MQ's `/beep` takes a file on this build; if it doesn't, leave Sound blank for the plain beep.
